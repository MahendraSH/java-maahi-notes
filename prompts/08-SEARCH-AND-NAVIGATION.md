# Phase 8 — Folders, Tags, Search and Links

Build on verified note persistence.

Requirements:
- Nested folders/pages with clear active selection.
- Tags visible on notes and usable for filtering.
- Search across note titles and content with empty/loading/error states as appropriate.
- Support note-to-note links and backlinks only if a stable note identifier/path convention exists.
- Add `⌘K`/`Ctrl+K` search access where practical and avoid keyboard traps.
- Restore last-open note/location only if persistence is reliable and privacy-safe.
- Never reuse a previous destination silently during quick capture.
- Avoid expensive indexing infrastructure for a local notes collection; start with a simple, tested implementation.
- Include no-results and broken-link states.
- Keep the UI usable with keyboard and screen reader.

Verify core interactions and builds. Stop at checkpoint.

## Module 1 — Handling Date, Time, Text, Numeric, and Boolean Values

**Folder:** `Certificates & Courses/java-se-21-1z0-830-cert-prep/module-01-handling-values-and-expressions`  
**Status:** Completed

This module covers primitive and wrapper types, operators, numeric promotions, type casting, references, aliasing, and object equality.

### Module Notes & Lessons

1. [[Module 1 Overview]] — High-level blueprint of the 3 exam objectives in this module.
2. [[Learning Objectives]] — Detailed topic checklist: evaluation rules, promotions, wrappers, equality.
3. [[Operators: Part 1]] — Precedence, L-values, side effects, evaluation order, increment/decrement, shift operators.
4. [[Operators: Part 2]] — Remainder operator (`%`) behavior with negative operands and arithmetic nuances.
5. [[Numeric Promotions & Expressions]] — Unary & binary promotions, mixed-type arithmetic, and ternary conditional expressions.
6. [[Type Casting]] — Widening vs narrowing, explicit syntax, floating-point to integer truncations, and boundary overflows.
7. [[Wrapper Classes]] — The 8 wrapper types, caching pools, autoboxing/unboxing mechanics, and null pitfalls.
8. [[Primitives, References & Equality]] — Primitives vs objects, references, aliasing, `==` identity vs `.equals()` value equivalence.
9. [[Deep Dive: Operator Evaluation]] — Exam walkthrough of complex array subscript evaluation with `++i`, `i++`, and compound assignment.

### Key Exam Concepts to Review

Before proceeding to Module 2, make sure you can answer:

- [x] Operator precedence vs left-to-right operand evaluation order
- [x] Differences between pre-increment (`++i`) and post-increment (`i++`) in subscripts
- [x] Binary numeric promotion rules (operands smaller than `int` promoted to `int`)
- [x] Wrapper caches (e.g. `Integer` caching between `-128` and `127`)
- [x] Reference identity (`==`) vs logical equivalence (`equals()`)
- [x] Compound assignments (`ia[i] += expr`) evaluation steps and side-effects

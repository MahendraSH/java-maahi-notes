# Java Operators — Part 2

## 1. The Remainder Operator (`%`)

The remainder operator returns the remainder after division. It is not the same as a mathematical modulus operation when negative operands are involved.

For positive operands, both operations produce the same result. With Java's remainder operator, the result's sign follows the left operand, provided the result is nonzero.

```java
System.out.println(7 % 3);    //  1
System.out.println(-7 % 3);   // -1
System.out.println(7 % -3);  //  1
System.out.println(-7 % -3); // -1
```

**Exam point:** Java's remainder operator preserves the sign of the dividend, the left-hand operand.

### Remainder and Array Indexes

Using `%` to generate an array index can cause an exception if the result is negative.

```java
int[] values = {10, 20, 30, 40, 50};
int index = -7 % values.length;

System.out.println(values[index]); // ArrayIndexOutOfBoundsException
```

The remainder is `-2`, which is not a valid array index.

## 2. Equality Operators: `==` and `!=`

The equality operators behave differently depending on whether their operands are primitive values or references.

- **Primitive values:** `==` tests whether the values are equal; `!=` tests whether they differ.
- **Reference values:** `==` tests whether both references identify the same object; `!=` tests whether they identify different objects.

For comparing object contents, Java provides the `equals()` method. Its behaviour depends on the class implementation.

```java
String a = new String("Hello");
String b = new String("Hello");

System.out.println(a == b);      // false
System.out.println(a.equals(b)); // true
```

The two references identify distinct objects, but the strings contain equal text.

### Important Exception: `StringBuilder`

`StringBuilder` does not override `equals()` to compare character contents. Its inherited implementation therefore compares object identity.

```java
StringBuilder a = new StringBuilder("Hello");
StringBuilder b = new StringBuilder("Hello");

System.out.println(a == b);      // false
System.out.println(a.equals(b)); // false
```

**Exam point:** Do not assume every Java class implements content-based equality. Check the specific class's `equals()` implementation

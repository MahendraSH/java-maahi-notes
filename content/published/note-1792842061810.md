# Module 1 — Handling Date, Time, Text, Numeric, and Boolean Values

## Module Overview

This module covers three exam objectives grouped under **Handling Date, Time, Text, Numeric, and Boolean Values**.

The objectives focus on primitive and wrapper classes, arithmetic and Boolean expressions, text manipulation, and the Java date-time API.

## 1. Primitive and Wrapper Classes

Use primitive types and their corresponding wrapper classes in Java.

## 2. Arithmetic and Boolean Expressions

Evaluate arithmetic and Boolean expressions using the Math API and Java's expression rules.

Topics include:

- Arithmetic and Boolean expressions.
- The Math API.
- Operator precedence rules.
- Type conversions.
- Casting.

## 3. Text and Date-Time Manipulation

### Text Manipulation

Manipulate text using Java's string-related classes.

- `String`
- `StringBuilder`
- Text blocks

### Date-Time Manipulation

Manipulate temporal values using the Java date-time API.

- Dates and times.
- Durations and periods.
- Instants.
- Time zones.
- Daylight saving time.

# Exam Deep Dive: Operator Evaluation, Side Effects, and Compound Assignment

## 1. Understanding the Question

This exam-style question tests how Java evaluates array expressions when they contain:

- Pre-increment (`++i`) and post-increment (`i++`).
- Array subscripts.
- Left-to-right operand evaluation.
- Assignment and compound assignment operators.
- Side effects that change a variable during expression evaluation.

The key is to track the value of `i` at each step and determine which array element each subexpression accesses.

Assume the array initially contains:

```java
int[] ia = {0, 1, 2, 3};
int i = 0;
```

## 2. Pre-Increment in an Array Subscript

The original expression's evaluation is explained using the following pattern:

```java
ia[++i] = /* expression */;
```

Pre-increment changes `i` before its value is used.

If `i` starts at `0`:

1. `++i` increments `i` to `1`.
2. The subscript evaluates to `1`.
3. The expression refers to the second array element.

Remember that Java array indexes begin at `0`.

| Index | Initial value |
|---:|---:|
| `0` | `0` |
| `1` | `1` |
| `2` | `2` |
| `3` | `3` |

## 3. Left-to-Right Evaluation and Side Effects

When an expression contains multiple operands, Java evaluates operands from left to right. An increment performed by one operand can therefore affect the values used by later operands.

For example, consider the pattern:

```java
ia[++i] = (ia = /* another array expression */) /* ... */;
```

When evaluating a complicated expression, track these separately:

1. The current value of `i`.
2. Whether the current operation increments `i`.
3. The array reference being used.
4. The index calculated by each subscript.
5. The final value assigned to the selected element.

Do not assume that every occurrence of `i` uses its initial value. An earlier increment may already have changed it.

## 4. Pre-Increment vs. Post-Increment

The distinction between `++i` and `i++` is essential.

| Expression | What happens | Value produced by the expression |
|---|---|---|
| `++i` | Increment first | The incremented value |
| `i++` | Use the current value, then increment | The original value |

For example:

```java
int i = 0;

int a = ++i; // i = 1, a = 1
int b = i++; // b = 1, i = 2
```

The value produced by `i++` is the value before the increment, even though the variable is incremented as part of evaluating the expression.

## 5. Compound Assignment: `+=`

Consider:

```java
ia[i++] += ia[i];
```

The important distinction is that compound assignment evaluates its left-hand operand only once.

Conceptually, Java determines the left-hand array element, obtains its existing value, evaluates the right-hand side, adds the values, and stores the result back into the selected element.

This differs from an ordinary assignment where a side-effecting expression might appear separately on the left and right.

For the example above, assuming `i` starts at `0` and `ia` is `{0, 1, 2, 3}`:

1. The left-hand subscript uses the original value `0`.
2. `i` is incremented to `1`.
3. The existing value at `ia[0]` is `0`.
4. The right-hand expression `ia[i]` reads `ia[1]`, which is `1`.
5. The sum is `0 + 1 = 1`.
6. The result is stored in `ia[0]`.

The array remains:

```text
[1, 1, 2, 3]
```

This illustrates how the left-hand element is selected once while the right-hand expression observes the updated value of `i`.

## 6. Tracking Multiple Post-Increments

When several subscripts use `i++`, each occurrence produces the current value and then increments `i`.

For example:

```java
int[] ia = {0, 1, 2, 3};
int i = 0;

int result = ia[i++] + ia[i++] + ia[i];
```

Evaluate from left to right:

| Step | Expression | Index/value used | `i` afterward |
|---:|---|---|---:|
| 1 | `ia[i++]` | `ia[0]` gives `0` | `1` |
| 2 | `ia[i++]` | `ia[1]` gives `1` | `2` |
| 3 | `ia[i]` | `ia[2]` gives `2` | `2` |

The result is `0 + 1 + 2 = 3`.

The central lesson is that every side effect influences the subsequent evaluation of the expression.

## 7. Why Assignment Form Matters

Compare these two general patterns:

```java
ia[indexExpression] = ia[indexExpression] + value;
```

```java
ia[indexExpression] += value;
```

If `indexExpression` has side effects, such as incrementing `i`, these forms are not necessarily equivalent.

With compound assignment, the left-hand operand is evaluated only once. Rewriting it as a normal assignment may evaluate a side-effecting index expression separately on the left and right.

**Exam technique:** Never simplify an expression containing increments, assignments, or other side effects without accounting for how many times each part is evaluated.

## 8. A Reliable Method for Exam Questions

Use this sequence whenever you encounter a complex array expression:

1. Write down the initial array contents and variable values.
2. Start evaluating the expression from left to right.
3. For every `++i`, increment first and then use the new value.
4. For every `i++`, use the current value and then increment.
5. Record the exact array index selected by each subscript.
6. For `+=`, remember that the left-hand operand is evaluated only once.
7. Calculate the right-hand value using the state of the variables at that point.
8. Update the selected array element.
9. Write the final array and compare it with the answer choices.

The instructor's central lesson is that **operator evaluation order, side effects, and the difference between compound assignment and ordinary assignment determine the result**.

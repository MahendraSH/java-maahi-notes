# Primitive Wrapper Classes & Autoboxing

## 1. What Are Wrapper Classes?

The `java.lang` package provides wrapper classes for all eight primitive types. Each wrapper provides a reference type that represents a primitive value and a place for related constants and utility methods.

| Primitive type | Wrapper class |
|---|---|
| `byte` | `Byte` |
| `short` | `Short` |
| `int` | `Integer` |
| `long` | `Long` |
| `float` | `Float` |
| `double` | `Double` |
| `char` | `Character` |
| `boolean` | `Boolean` |

The wrapper names begin with capital letters. `int` and `char` use the full names `Integer` and `Character`; the other wrappers use the primitive name with its first letter capitalized.

Java also has a class named `Void`, but it does not wrap a primitive value. It has no instances and is associated with the absence of a value.

### Why Do Wrapper Classes Matter?

Wrapper classes provide:

- **Reference types** that represent primitive values.
- **Constants and utility methods**, such as `Integer.MAX_VALUE`.
- **Conversion and comparison methods** for working with primitive values and their textual representations.
- **Compatibility with generics and collections**, which require reference types rather than primitive types.

For example, `List<Integer>` is valid, but `List<int>` is not.

```java
List<Integer> numbers = new ArrayList<>();
numbers.add(99);
```

Java generics do not support primitive type arguments directly, so wrapper classes are used instead.

## 2. Autoboxing and Unboxing

The compiler can automatically convert between primitive values and their corresponding wrapper objects. These conversions are called **autoboxing** and **unboxing**.

### Autoboxing

Autoboxing converts a primitive value into its corresponding wrapper object.

```java
Integer intg = 99;
```

The compiler automatically boxes the primitive `int` value `99` into an `Integer` object.

### Unboxing

Unboxing extracts the primitive value from a wrapper object.

```java
Integer intg = Integer.valueOf(99);
int value = intg;
```

The compiler automatically extracts the `int` value from `intg`.

### Combining Unboxing with Primitive Widening

A wrapper value can be unboxed and then widened to another primitive type.

```java
Integer intg = Integer.valueOf(99);
long value = intg;
```

The compiler unboxes `intg` to an `int`, then widens that `int` to a `long`.

### Autoboxing to an Object Reference

A primitive can also be boxed and assigned to a compatible reference type.

```java
int value = 99;
Object obj = value;
```

The compiler boxes `value` into an `Integer`, which can then be assigned to an `Object` reference.

## 3. A Conversion Combination That Does Not Compile

Java does not support every combination of boxing and primitive conversion in a single assignment.

For example:

```java
Long value = 99; // Does not compile
```

Here, `99` is an `int` literal. The compiler cannot directly combine boxing it into an `Integer` with converting it to a `Long`.

Use a `long` literal instead:

```java
Long value = 99L;
```

The `L` makes the literal a `long`, which can then be boxed into a `Long`.

**Exam point:** Pay attention to the source primitive type, target wrapper type, and the conversions required between them. A conversion that seems logically possible is not necessarily permitted by Java's assignment conversion rules.

## 4. Wrapper-Class Methods and Constants

Wrapper classes provide numerous utility methods. For the certification exam, become familiar with their general purpose and recognize what common method names imply.

### Constants

Numeric wrappers provide constants describing the limits of their primitive types.

```java
System.out.println(Integer.MAX_VALUE);
```

`Integer.MAX_VALUE` represents the largest value that an `int` can hold.

### Extracting Primitive Values

Numeric wrappers, other than `Boolean` and `Character`, provide methods for extracting numeric primitive values.

Examples include:

```java
Integer intg = Integer.valueOf(99);

int i = intg.intValue();
float f = intg.floatValue();
double d = intg.doubleValue();
```

These methods return the wrapped value converted to the requested numeric primitive type.

### Comparison Methods

Numeric wrappers provide comparison methods.

- `Integer.compare(int x, int y)` is a static method that accepts two primitive `int` arguments and returns an `int` indicating their ordering.
- `compareTo()` compares a wrapper object with another compatible wrapper object.

Example:

```java
int result = Integer.compare(10, 20);
```

### String Conversion

Wrapper classes also provide methods for converting values to and from strings.

For example:

```java
String hex = Double.toHexString(3.2);
double value = Double.parseDouble("3.2");
```

`Double.toHexString()` produces a hexadecimal string representation of a `double`. `Double.parseDouble()` parses a string into a primitive `double`.

The method names are usually descriptive, so focus on recognizing their purpose rather than memorizing every wrapper method.

## 5. Special Floating-Point Values: NaN and Infinity

`Float` and `Double` support special floating-point values, including:

- `NaN` — Not a Number.
- Positive infinity.
- Negative infinity.

These values can be parsed from suitable strings.

```java
double nan = Double.parseDouble("NaN");
double infinity = Double.parseDouble("Infinity");
```

A string that cannot be interpreted as a valid numeric representation causes a `NumberFormatException`.

### Testing Special Values

The `Double` and `Float` classes provide methods such as:

- `isNaN()` — tests whether a value is NaN.
- `isFinite()` — tests whether a value is finite.
- `isInfinite()` — tests whether a value is positive or negative infinity.

Example:

```java
double value = Double.parseDouble("NaN");

System.out.println(Double.isNaN(value));      // true
System.out.println(Double.isFinite(value));   // false
System.out.println(Double.isInfinite(value)); // false
```

NaN is neither finite nor infinite, so it passes neither of the latter two tests.

Infinity, however, is not finite, but it is infinite.

## 6. Certification-Style Questions

### Question 1: How many arguments does `Integer.compare()` take, and what are their types?

```java
Integer.compare(10, 20);
```

**Answer:** Two arguments, both primitive `int` values.

### Question 2: Which method extracts a primitive `float` from an `Integer` object?

```java
Integer intg = Integer.valueOf(99);
float value = intg.floatValue();
```

**Answer:** `Integer.floatValue()`.

### Question 3: Does this compile?

```java
Integer intg = Integer.valueOf(0);
System.out.println(intg.booleanValue());
```

**Answer:** No. `Integer` has no `booleanValue()` method. An `Integer` represents an integer value, not a Boolean value.

### Question 4: What does this print?

```java
System.out.println(
    Double.isNaN(Double.parseDouble("NaN"))
);

System.out.println(
    Double.isFinite(Double.parseDouble("NaN"))
);

System.out.println(
    Double.isInfinite(Double.parseDouble("NaN"))
);
```

**Answer:**

```text
true
false
false
```

`NaN` is not a number, so `isNaN()` returns `true`. It is neither finite nor infinite, so the other two methods return `false`.

## 7. Exam Focus

When reviewing wrapper classes, concentrate on:

- The mapping between all eight primitive types and their wrappers.
- Why collections use wrapper types instead of primitives.
- The difference between autoboxing and unboxing.
- How unboxing can combine with primitive widening.
- Which combinations of boxing and primitive conversion compile.
- Common constants and utility methods, including `MAX_VALUE`, `compare()`, `compareTo()`, and value-extraction methods.
- Parsing numeric strings and handling `NumberFormatException`.
- The behavior of `NaN`, infinity, `isNaN()`, `isFinite()`, and `isInfinite()`.

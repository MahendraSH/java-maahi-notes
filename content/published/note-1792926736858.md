# Module 1 — Learning Objectives

## Learning Objectives

This lesson covers the following Java language concepts:

## 1. Operators and Evaluation

- Java operators and their precedence.
- L-values.
- Side effects.
- Order of evaluation of operands.

## 2. Type Promotion and Casting

- Promotion of operands.
- Type casting.
- Special initialization rules involving constant expressions.
- Types of conditional expressions, including the ternary conditional operator (`?:`) and switch expressions.

## 3. Wrapper Classes

- The purpose and features of wrapper classes.
- Autoboxing and unboxing.
- Rules governing autoboxing and unboxing, and their effects.

## 4. Primitive and Reference Types

- Differences between primitive types and reference types.
- Aliasing: when two references refer to the same object.

## 5. Equality and the `equals()` Method

- Equality in Java.
- Rules for implementing the `equals()` method.
